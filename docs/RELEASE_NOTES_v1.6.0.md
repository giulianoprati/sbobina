## Sbobina 1.6.0 (build 10)

### What's new
- **Update from inside the app.** Once a day, when you open Sbobina, it checks whether a newer release is available on GitHub. If so, a dialog shows your version and the new one; *Update* downloads the APK, verifies it and opens the Android installer. Your model and history are kept.
- The first time, Android asks you to allow Sbobina to install apps. You always confirm the installation in the system screen.
- The only network traffic is now the model download and this once-a-day check (see the README, "In-app updates").

**This version must be installed by hand** over 1.5.2 or earlier; from here on, updates arrive from the app.

Full list: [CHANGELOG.md](https://github.com/giulianoprati/sbobina/blob/master/CHANGELOG.md)

### Install
Android 10+, arm64. Download `Sbobina.apk`, allow "Install unknown apps", open it and download the model once (Wi-Fi recommended). Updates over the previous version keep your model and history.
