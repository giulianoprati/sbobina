## Sbobina 1.4.0 (build 6)

Offline Italian transcription of WhatsApp voice notes, powered by whisper.cpp. Share an audio file to Sbobina and read the text; nothing leaves your phone.

### Added
- Light-hearted messages under the progress bar while a transcription runs.
- **Statistics** screen (⋮ menu): transcriptions, audio length, words and estimated typing time saved.

### Since 1.0
- Model picker (*Preciso* `large-v3-turbo` q5_0 ≈ 574 MB / *Veloce* `small` q5_1 ≈ 190 MB), low-memory warning, crash report on next launch.
- History with search, "Transcription ready" notification, SHA-256 model verification.
- Fix: native crash on Pixel 6/7 (Tensor G1/G2).

Full list: [CHANGELOG.md](https://github.com/giulianoprati/sbobina/blob/master/CHANGELOG.md)

### Install
Android 10+, arm64. Download `Sbobina.apk`, allow "Install unknown apps", open it and download the model once (Wi-Fi recommended).
